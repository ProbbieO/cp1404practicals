# CP1404 Practicals
## By Paul Omuyoma

Repository contains practical exercises for the CP1404 Programming II unit at JCU.

### ✅ Lessons I’ve learnt about clean code:
- Use clear naming and follow naming conventions for variables, functions and classes.
- Apply SRP (Single Responsibility Principle) – each function/class should do one job well.
- Avoid repetition (DRY) by using functions, constants, and reusable logic.
